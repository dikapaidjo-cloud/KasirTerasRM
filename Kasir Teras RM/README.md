# Teras RM POS

Aplikasi kasir ringan untuk Teras RM: React + Vite, Express, SQLite, export Excel, PWA, dan siap jalan di Docker.

## Jalankan dengan Docker

```bash
docker compose up --build
```

Buka:

```txt
http://localhost:3000
```

Untuk perangkat lain di WiFi/LAN yang sama, buka IP komputer utama:

```txt
http://IP-KOMPUTER:3000
```

## Development lokal

```bash
npm install
npm run dev
```

Client berjalan di `http://localhost:5173`, API di `http://localhost:3000`.
